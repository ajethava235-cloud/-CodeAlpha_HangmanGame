# Hangman Game 🎮

A simple text-based Hangman game built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The player tries to guess a hidden word one letter at a time. The word is chosen randomly from a predefined list of 5 words. The player has 6 incorrect guesses allowed before losing the game.

## Features
- Random word selection from a predefined list
- Tracks correct and incorrect guesses
- Limits incorrect guesses to 6
- Simple console-based input/output

## Key Concepts Used
`random`, `while` loop, `if-else`, strings, lists

## How to Run
```bash
python hangman.py
```
